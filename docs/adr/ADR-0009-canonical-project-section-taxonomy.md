# ADR-0009: Canonical Project Section Taxonomy

* **Status:** Accepted
* **Date:** 2026-08-26
* **Specification:** `VHOS-PHASE-001` / `SPEC-001`

## Context
Ventures need standard strategic categorization that is decoupled from presentation slide sequences.

## Decision
We define 17 canonical section types:
`IDENTITY`, `EXECUTIVE_SUMMARY`, `PROBLEM`, `CUSTOMER`, `SOLUTION`, `WHY_NOW`, `MARKET`, `PRODUCT`, `BUSINESS_MODEL`, `COMPETITION`, `TRACTION`, `FINANCIALS`, `TECHNOLOGY`, `RISKS`, `ROADMAP`, `TEAM`, `ASK`.
Sections are identified by business purpose, not slide numbers (`slide1`, `slide2`).

## Consequences
* **Positive:** Consistent taxonomy across all ventures; presentation views and compilers can map to sections arbitrarily.

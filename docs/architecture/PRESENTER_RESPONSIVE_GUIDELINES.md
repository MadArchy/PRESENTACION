## 1. Supported Cockpit Viewports

- **Executive Presenter Desktop (1440×900 & 1280×720):** Dual split-panel layout (Left: scaled scene preview + notes; Right: next slide preview + trust alerts + Q&A).
- **Tablet (1024×768):** Compact timers and collapsible context drawers.
- **Mobile (390×844):** Single-column stacked cockpit with touch action buttons and drawer modals.
